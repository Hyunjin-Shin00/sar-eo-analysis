# 분석 결과 리포트

- 이 모듈의 코드로 만든 결과를 HTML 로 정리한 문서임
- 파일 용량이 커 저장소에는 두지 않고 **공개 사이트에서 직접 열람**하는 방식임
- 원본 위성영상·중간 산출물은 미포함

| 문서 | 형식 | 내용 |
|---|---|---|
| [지바 호우 침수 판독](https://hyunjin-shin00.github.io/reports/flood-sar/chiba-flood-mapping.html) | 리포트 | 호우 전후 SAR 영상 비교로 침수 범위 판독. 기준영상·판정 근거 수록 |

> - 대화형 지도는 파일이 수 MB~십수 MB 수준이므로 최초 로딩에 시간 소요
> - 고객사명·담당자·계약 정보는 제외한 상태임
