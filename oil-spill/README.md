# oil-spill — SAR 기름유출 탐지

기름막은 해수면의 모세관파를 감쇠시켜 Bragg 산란을 줄인다.
그래서 SAR에서 주변보다 **어둡게(dark spot)** 보인다.

## 파일

`notebooks/oil_spill.ipynb` — Sentinel-1 GRD 전처리 → dark spot 추출 → 형상 필터 → 시각화

## 적용

- 에콰도르 해안 (2025.12)
- 이란 카르그섬, 페르시아만 (2026.05)

## 오탐지 구분이 핵심

dark spot이 전부 기름은 아니다. 다음과 구분해야 한다.

| 유사 현상 | 구분 단서 |
|---|---|
| 저풍속 구역 | 기상 자료로 풍속 확인 (3 m/s 미만이면 판정 보류) |
| 해조류 패치 | 경계가 불규칙·분산적, 시간에 따라 모양 유지 |
| 해빙 / 강우 셀 | 광학 영상 교차 확인 |
| 선박 항적 | 선형, 선박 탐지 결과와 대조 |

풍속이 너무 낮으면 바다 전체가 어두워 탐지가 불가능하고,
너무 높으면 파랑이 기름막을 흩어 신호가 사라진다. 적정 구간이 있다.
