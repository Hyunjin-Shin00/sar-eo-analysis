# [연구개발계획서] 구리 제련소 열원 탐지 및 모니터링

> - 원문: 사내 Confluence 기술문서 (2025-08 최종수정) · 참여 4인 (본인 포함)

> - 공개 저장소 이관 시 **담당자 실명·참여율·내부 보드 링크 제외**
> - 관련 코드: [`eo/sentinel-2/thermal-anomaly/`](../../eo/sentinel-2/thermal-anomaly/)

## 1. 개요

- 전 세계 구리 제련소 열원을 위성으로 탐지·모니터링함
- 적외 위성 시계열 자료로부터 용광로 활동성 지수를 산출하고 생산량 현황 예측 모델 개발
- 목적: 글로벌 원자재 시장 거래자에게 **공식 통계보다 빠르게** 구리 생산량 변화 정보 제공
- 공식 지표는 통상 1개월 지연 발생
- 위성 데이터로 산업 활동량을 추정하면 그보다 앞서 시장 가격 변동 의사결정 근거 제공 가능

---

| 산출물 | 형태 | 활용 |

| API 기반 영상 다운로드 코드 | 파이썬 | 전 세계 구리 제련소 지역 영상 수집 |

| 특허 | — | 위성영상 기반 제련 활동 모니터링 솔루션 |
| 솔루션 서비스 | — | 원자재 시장 거래자 대상 구리 생산 현황 추정 정보 |

## 3. 필요 자원

**컴퓨팅**

- GPU 1대 이상
- 스토리지 100 TB 이상 (300~400 TB 급 희망)

**확보 계획**

- 사내 팀서버 활용 (HDD 24 TB급 RAID0, RAM 128 GB, 16코어 CPU, GPU 3장)

---

## 4. 작업상 어려운 점

- **GT 확보** — 구리 생산량 기준자료(ICSG 통계) 구입 필요. 기업은 가동률 미공개
- **AOI 제작** — 전 세계 100개소 이상의 구리 제련소를 공정 지식 기반으로 개별 확인·판단하여 수동 폴리곤 제작 필요. 용광로·슬래그장·원료야적장 구분이 되어야 집계가 안정됨
- **구름 탐지** — 픽셀 레벨 구름 분할 마스크 성능 향상 필요
- **대용량 처리** — 방대한 원본 영상 자료 핸들링
