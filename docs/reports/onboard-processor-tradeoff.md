# 온보드 프로세서 탑재 유무에 따른 이점 분석

> - 원문: 사내 발표자료 (2025, v1.3) · 작성 신현진
> - 발표자료 내용을 이관한 문서임. 수치는 원문 그대로임

---

## 1. 무엇을 따진 것인가

- 기존 인공위성은 촬영한 RAW 데이터를 지상국으로 그대로 전송함
- PlanetScope 8밴드 기준 한 장면이 약 1~1.4 GB
- **온보드 프로세서(OBP)** 탑재 시 이점 2가지
  1. **대기 시간 활용** — 지상국 교신 전 대기 시간에 위성이 자체 처리해 최종 결과물 생성
  2. **전송량 감소** — RAW 대신 축소된 결과물만 전송하여 다운링크 시간 단축
- 단, **1번은 온보드 프로세서 성능에 좌우됨**
  - 지상국 교신 전 처리 완료 시 효과적
  - 미완료 시 다음 교신까지 대기 필요
- 본 분석은 단일 수신 지상국 전제이며, 처리 지연 시 **최대 4회 추가 공전** 소요 가능으로 가정함

## 2. 가정

| 항목 | 값 |
|---|---|
| RAW 데이터 용량 | 2 GB (시나리오에서는 1 GB 기준으로 계산) |
| 최종 산출물 용량 | **1 MB** — 선박 위치정보 파일 크기를 고려해 선정 |
| 처리 컴퓨팅 파워 | 일반 컴퓨터 수준 |
| 지상국 교신 대기 | 2,000 초 |

### 다운링크 속도

| 위성 | X-band 속도 | 1 GB 전송 | 1 MB 전송 |
|---|---:|---:|---:|
| SkySat | 72.5 MB/s | 14.12 초 | 0.01 초 |
| BlueBON | **3.75 MB/s** | 273.07 초 | 0.27 초 |

> BlueBON 수신 속도는 원문에 확인 필요 값으로 표기됨

### 지상 처리 시간 (Sentinel-2 기준)

- 전처리 후 배포까지: 약 **3~18 시간** (min 3시간 51분 ~ max 19시간 30분)
- 대기보정: 약 36분 ~ 1시간
- LAI 등 산출물 제작: 15~30분

## 3. 시나리오 비교

- 총 서비스 지연시간(촬영 → 배포)을 지상처리(GS)와 온보드처리(OBP)로 구분해 계산함
- `n`은 처리가 교신 시점까지 완료되지 않아 **추가로 필요한 공전 횟수**

| 구성요소 (초) | GS | OBP best | OBP n=1 | OBP n=2 | OBP n=3 |
|---|---:|---:|---:|---:|---:|
| 관측 | 0 | 0 | 0 | 0 | 0 |
| 지상국 교신 대기 | 2,000 | 2,000 | 2,000 | 2,000 | 2,000 |
| 온보드 처리 | 0 | 1,000 | 3,000 | 12,000 | 18,000 |
| 스케줄링 효율 | 2,000 | 2,000 | 7,400 | 12,800 | 18,200 |
| RAW 다운링크 | 281.25 | 0.27 | 0.27 | 0.27 | 0.27 |
| 지상 처리 | 13,860 | 0 | 0 | 0 | 0 |
| 배포 | 0.01 | 0.01 | 0.01 | 0.01 | 0.01 |
| **총 서비스 지연** | **16,141.26** | **2,000.28** | **7,400.28** | **12,800.28** | **18,200.28** |
| GS 대비 | 100% | **12.39%** | 45.84% | 79.30% | **112.76%** |

---

## 4. 결론

- **온보드 처리의 이득은 처리 속도에 좌우되며, 처리가 느려지면 역전됨**
- 지상국 교신 전 처리 완료 시(best) 총 지연이 GS의 **12.39%** 로 감소 — 약 8배 단축
- 추가 공전 1회 시 45.84%, 2회 시 79.30%로 이득 급감
- **추가 공전 3회 시 112.76%로 지상 처리보다 오히려 지연됨**
- 이득의 대부분은 지상 처리 시간(13,860초) 제거에서 발생
- 다운링크 절감(281 → 0.27초)이 전체 지연에서 차지하는 비중은 작음
- 즉 **온보드 처리의 가치는 "전송량 축소"보다 "지상 처리 대기열 우회"에 있음**
- 따라서 탑재 판단 기준은 온보드 프로세서가 **1회 교신 주기 내 처리 완료 가능 여부**
- 미완료 시 추가 공전마다 손익이 급격히 악화되며, 3회차부터는 미탑재가 유리함

---

## 5. 이 분석의 한계

- **단일 수신 지상국** 전제. 지상국이 복수인 경우 교신 대기·추가 공전 가정이 달라짐
- 최종 산출물 1 MB는 선박 위치정보 기준. 산출물이 영상인 경우 전송량 이득 대폭 감소
- 지상 처리 시간은 Sentinel-2 운영 실적 기준이므로 자체 지상 시스템 처리 속도와 상이할 수 있음
- BlueBON 다운링크 속도(3.75 MB/s)는 확인 필요 값으로 잔존
