## 1. 배경 및 필요성

중남미에는 SRTM (30 m), ASTER GDEM (30 m), Copernicus GLO-30 (30 m), ANADEM (30 m) 등
무료 저해상도 DTM 이 존재하나 **고해상도 DTM 이 부족**하다.

- 저비용 DSM·DTM 구축은 개발도상국, 오지 탐사, 국방·안보 지역에서 수요가 있다
- 고해상도 DTM 은 유량 시뮬레이션과 인프라 설계의 전제조건이다

**목표:** 최소한의 비용으로 중남미 지역의 5~10 m 해상도 DTM 구축

## 2. 기존 연구·개발 동향

### 2.1 스테레오 영상 기반

1. **영상 전처리** — 정사보정(orthorectification), RPC 보정으로 위치 정확도 향상
2. **스테레오 정합** — 좌/우 영상 간 동일 지점을 찾아 시차로 고도 추출
3. **DSM 생성** — 정합 결과를 3D 포인트로 변환해 표고 모델 생성
4. **객체 제거** — 식생·건물 제거 후 DTM 추출, 필터링
5. **보간·보정** — 제거 후 빈 공간 보간, 경계 평활화

### 2.2 LiDAR 기반

1. **포인트 클라우드 수집** — 레이저 반사 정보를 X, Y, Z 좌표로 저장
2. **반사 신호 분류** — '지면', '건물', '식생' 등으로 분류
3. **지면 점만 추출** — Ground class 만 필터링
4. **보간 → DTM 생성** — 삼각망(TIN) 또는 래스터 보간

### 2.3 InSAR 기반

1. **코히런트 SAR 영상 준비** — 시간 차가 짧고 지표 변화가 적은 영상 2장
2. **간섭도 생성** — 위상 차 추출
3. **위상 보정** — 기압·대기·궤도 오차 제거 (orbital refinement, filtering)
4. **Unwrapping** — 위상이 2π 단위로 반복되므로 절대 위상 복원
5. **DEM 추출** — 위상차 → 고도값 변환 (baseline 정보 활용)
6. **필터링 → DTM 파생** — DSM 에서 비지형 요소 제거

## 3. 데이터 구축 및 전처리

### 3.1 LiDAR (검증용 참값)

멕시코 지역 **0.5 m 해상도** LiDAR 데이터 확보. 이 지역은 0.5 m DSM 과 DTM 이 모두 존재해
제작 결과를 정량 검증할 수 있는 유일한 곳이었다.

### 3.2 ALOS World 3D (30 m) 기반 DSM → DTM

콜롬비아 지역에 적용한 처리 순서:

| 단계 | 내용 |
|---|---|
| **Hillshade** | 표고 데이터를 시각화해 지형의 음영 효과 생성. 태양 방향을 고려해 음영을 시뮬레이션 |
| **DTM filter (slope-based)** | 경사도 분석. 경사 **10° 이하** 평탄부는 지표면(DTM) 후보로, 경사가 높은 부분은 건물·식생으로 판단해 제거. 임계값은 데이터 특성에 따라 조정 |
| **Close gaps (stepwise resampling)** | 제거된 빈 공간을 주변 지형 표고로 점진적 보간 |
| **Gaussian filter** | 표면 평활화. 노이즈를 줄이고 급격한 경계를 완만하게 만들어 현실적인 지면 모델 생성 |

### 3.3 Sentinel-1 SLC (DSM 제작용)

페어 선정 기준:

- perpendicular baseline: **150~300 m**
- temporal baseline: **7개월 미만** (가능한 짧게)

적용 지역·시기:

| 지역 | 궤도 | 날짜 |
|---|---|---|
| 이란 | ASC | 20190616 / 20190926 |
| 볼리비아 | ASC (path 76, frame 1110) | 20240327 / 20240408 |
| 볼리비아 | DSC (path 156, frame 658 / 663) | 20240719 / 20240731 |

전처리 (SNAP):

```
split → orbit file → back geocoding → interferogram → deburst
      → filtering → unwrapping → phase to elevation → subset → terrain correction
```

### 3.4 SPOT-5 스테레오

전·후방 스테레오 쌍 (HRS-1 / HRS-2) 으로 DSM 생성.
**중남미 일부 지역에만 존재**하므로 전역 커버는 어렵다.

## 4. 결과

### 4.1 ALOS World 3D (30 m) 기반 DTM

- DTM 제작 시 비지형 객체를 제거하고 보간하기 때문에 결과가 **사각형 모양**으로 나타난다
- 비교할 DTM 자료가 없어 **정량 비교 불가능**

### 4.2 Sentinel-1 InSAR DSM

**식생이 없는 지역에서 정확도가 높다.**

| 궤도 | temporal baseline | perpendicular baseline | 결과 |
|---|---|---|---|
| ASC | 102일 | 171 m | SRTM·Copernicus DSM 끼리는 유사하나 제작 DSM 에 오차 존재 |
| DSC | 12일 | 157 m | **평균 오차 41 m (0.8%)** |

제작 범위: **80 × 130 km**, 해상도 **14 m** (SRTM 30 m 대비 향상)

### 4.3 COSMO-SkyMed InSAR DSM

CSK 1 기반 DSM 을 제작해 SRTM 과 비교.

### 4.4 LiDAR DSM → DTM 변환 검증

제작한 DTM 과 실제 DTM 간 오차:

| 지표 | 값 |
|---|---|
| 평균 오차 | **0.7 m (0.76%)** |
| 최대 오차 | 30 m (약 32.6%) |

## 5. 한계

- **정량 검증 지역이 하나뿐이었다.** 멕시코 LiDAR 지역을 제외하면 비교 가능한 고해상도 참값이 없어
  제작 결과의 정확도를 수치로 확인할 수 없었다.
- InSAR DSM 은 식생이 있는 지역에서 정확도가 떨어진다. 식생 투과가 안 되는 C-band 특성상
  산출된 것은 엄밀히 DSM 이고, 여기서 DTM 을 얻으려면 비지형 객체 제거가 또 필요하다.
- SPOT-5 스테레오는 커버리지가 제한적이라 전역 적용이 불가능하다.
