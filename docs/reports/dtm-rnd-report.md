## 1. 배경 및 필요성

- 중남미에는 SRTM(30 m), ASTER GDEM(30 m), Copernicus GLO-30(30 m), ANADEM(30 m) 등 무료 저해상도 DTM만 존재
- **고해상도 DTM 부재**
- 저비용 DSM·DTM 구축 수요처: 개발도상국, 오지 탐사, 국방·안보 지역
- 고해상도 DTM은 유량 시뮬레이션·인프라 설계의 전제조건
- **목표: 최소 비용으로 중남미 지역 5~10 m 해상도 DTM 구축**

## 2. 기존 연구·개발 동향

### 2.1 스테레오 영상 기반

1. **영상 전처리** — 정사보정(orthorectification), RPC 보정으로 위치 정확도 향상
2. **스테레오 정합** — 좌/우 영상 간 동일 지점 탐색 후 시차로 고도 추출
3. **DSM 생성** — 정합 결과를 3D 포인트로 변환해 표고 모델 생성
4. **객체 제거** — 식생·건물 제거 후 DTM 추출·필터링
5. **보간·보정** — 제거 후 빈 공간 보간, 경계 평활화

### 2.2 LiDAR 기반

1. **포인트 클라우드 수집** — 레이저 반사 정보를 X, Y, Z 좌표로 저장
2. **반사 신호 분류** — '지면', '건물', '식생' 등으로 분류
3. **지면 점 추출** — Ground class만 필터링
4. **보간 → DTM 생성** — 삼각망(TIN) 또는 래스터 보간

### 2.3 InSAR 기반

1. **코히런트 SAR 영상 준비** — 시간 차가 짧고 지표 변화가 적은 영상 2장
2. **간섭도 생성** — 위상 차 추출
3. **위상 보정** — 기압·대기·궤도 오차 제거 (orbital refinement, filtering)
4. **Unwrapping** — 위상이 2π 단위로 반복되므로 절대 위상 복원
5. **DEM 추출** — 위상차 → 고도값 변환 (baseline 정보 활용)
6. **필터링 → DTM 파생** — DSM에서 비지형 요소 제거

## 3. 데이터 구축 및 전처리

### 3.1 LiDAR (검증용 참값)

- 멕시코 지역 **0.5 m 해상도** LiDAR 데이터 확보
- 해당 지역은 0.5 m DSM·DTM이 모두 존재 → 제작 결과의 정량 검증이 가능한 **유일한 지역**

### 3.2 ALOS World 3D (30 m) 기반 DSM → DTM

콜롬비아 지역 적용 순서

| 단계 | 내용 |
|---|---|
| **Hillshade** | 표고 데이터를 시각화해 지형 음영 효과 생성. 태양 방향을 고려해 음영 시뮬레이션 |
| **DTM filter (slope-based)** | 경사도 분석. 경사 **10° 이하** 평탄부는 지표면(DTM) 후보, 경사가 높은 부분은 건물·식생으로 판단해 제거. 임계값은 데이터 특성에 따라 조정 |
| **Close gaps (stepwise resampling)** | 제거된 빈 공간을 주변 지형 표고로 점진적 보간 |
| **Gaussian filter** | 표면 평활화. 노이즈 저감·급격한 경계 완화로 현실적인 지면 모델 생성 |

### 3.3 Sentinel-1 SLC (DSM 제작용)

페어 선정 기준

- perpendicular baseline: **150~300 m**
- temporal baseline: **7개월 미만** (가능한 짧게)

적용 지역·시기

| 지역 | 궤도 | 날짜 |
|---|---|---|
| 이란 | ASC | 20190616 / 20190926 |
| 볼리비아 | ASC (path 76, frame 1110) | 20240327 / 20240408 |
| 볼리비아 | DSC (path 156, frame 658 / 663) | 20240719 / 20240731 |

전처리 (SNAP)

```
split → orbit file → back geocoding → interferogram → deburst
      → filtering → unwrapping → phase to elevation → subset → terrain correction
```

### 3.4 SPOT-5 스테레오

- 전·후방 스테레오 쌍(HRS-1 / HRS-2)으로 DSM 생성
- **중남미 일부 지역에만 존재**하여 전역 커버 곤란

## 4. 결과

### 4.1 ALOS World 3D (30 m) 기반 DTM

- DTM 제작 시 비지형 객체 제거·보간으로 결과가 **사각형 형태**로 나타남
- 비교 가능한 DTM 자료 부재로 **정량 비교 불가**

### 4.2 Sentinel-1 InSAR DSM

- **식생이 없는 지역에서 정확도 높음**

| 궤도 | temporal baseline | perpendicular baseline | 결과 |
|---|---|---|---|
| ASC | 102일 | 171 m | SRTM·Copernicus DSM 간에는 유사하나 제작 DSM에 오차 존재 |
| DSC | 12일 | 157 m | **평균 오차 41 m (0.8%)** |

- 제작 범위: **80 × 130 km**
- 해상도: **14 m** (SRTM 30 m 대비 향상)

### 4.3 COSMO-SkyMed InSAR DSM

- CSK 1 기반 DSM 제작 후 SRTM과 비교

### 4.4 LiDAR DSM → DTM 변환 검증

제작 DTM과 실제 DTM 간 오차

| 지표 | 값 |
|---|---|
| 평균 오차 | **0.7 m (0.76%)** |
| 최대 오차 | 30 m (약 32.6%) |

## 5. 한계

- **정량 검증 지역이 1개소뿐이었음.** 멕시코 LiDAR 지역 외에는 비교 가능한 고해상도 참값이 없어 정확도 수치화 불가
- InSAR DSM은 식생 지역에서 정확도 저하. 식생 투과가 되지 않는 C-band 특성상 산출물은 엄밀히 DSM이며, DTM 획득에는 비지형 객체 제거가 추가로 필요
- SPOT-5 스테레오는 커버리지 제한으로 전역 적용 불가
