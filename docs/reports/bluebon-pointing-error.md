## 요약

- 촬영 위치 편차의 원인을 위성 제조사 제공 궤도·자세 메타데이터로 설명하려는 분석임
- 단일변수 상관분석 결과, **전체 65건 기준 모든 오차 유형에서 경과일(시간 드리프트)만이 유의미한 상관**을 보임
- across 오차에서는 Tilt(roll)에서도 약한 음의 상관 확인
- 텔레메트리 보유 27건에 한해 `|Δalt|`, `ECEF_Vz`, `ECI_Vy` 등 궤도·속도 파라미터가 along·total 오차와 유의한 상관을 보였으나, 표본 수가 적어 일반화 한계 존재
- 이상치 분석에서 **이상치 그룹과 정상 그룹 간 통계적으로 유의한 파라미터 차이 미확인**
- 즉 이상치는 단일 원인으로 설명되지 않음

## 1. 분석 설계

### 데이터

- 전체 **65건**
- 그중 텔레메트리(GNSS, 각속도, 속도 등) 보유 **27건**

### 왜 상관계수를 세 개 보는가

- 표본이 작아 단일 계수만으로는 판단 곤란

| 계수 | 성격 | 쓰는 이유 |
|---|---|---|
| **Pearson** *r* | 정비례/반비례 직선 관계만 감지 | 기준선 |
| **Spearman** *ρ* | 값 대신 순위로 상관을 봄. 직선이 아니어도 한쪽이 커질 때 다른 쪽도 커지면 감지. 이상치에 덜 민감 | 비선형 관계 포착 |
| **Kendall** *τ* | 모든 데이터 쌍을 비교해 같은 방향으로 움직이는 쌍의 비율 | **데이터가 20건대로 적을 때 p-value 가 더 정확** |

- p-value는 해당 상관이 우연일 확률이며, 0.05 미만이면 우연이 아닌 것으로 판단함

## 3. 이상치 분석

- 추세선 잔차로 이상치를 식별하고, 이상치 그룹과 정상 그룹의 파라미터 분포를 boxplot으로 비교함
- **결과: 두 그룹 간 통계적으로 유의한 파라미터 차이 미확인**
- 이상치 발생 원인은 본 분석으로 설명되지 않음. 설명하지 못한 사실을 그대로 기록함

## 4. 메타데이터 항목의 의미

| 항목 | 의미 |
|---|---|
| `Alt_GNSS` (km) | GNSS 수신기로 실측한 위성의 해수면 기준 고도 |
| `Alt_TLE` (km) | TLE 기반으로 계산한 예측 고도. TLE(Two-Line Element)는 궤도 예측용 요약 정보 |
| `GPS_Sats` | 해당 시점에 수신 가능한 GPS 위성 개수 |
| `AngRate_@` (°/s) | 위성 본체의 @축 회전 각속도. 촬영 시점에 이 값이 크면 자세가 불안정한 상태 |
| `ECEF_V@` (m/s) | 지구 고정 좌표계에서의 @방향 속도 |
| `ECI_V@` (m/s) | 관성 좌표계 속도. 지구 자전 효과가 빠진 우주 공간 기준. TLE 에서 계산 |
| `TimeDiff_GNSS_OBC` | GNSS 시각과 OBC(위성 컴퓨터) 시각의 차이. 크면 촬영 타이밍이 밀려 오차 발생 |

## 5. 남은 것

- 이상치 원인 미규명. 단일 파라미터로 설명되지 않으므로 다변량 분석 또는 추가 텔레메트리 항목 필요
- 텔레메트리 보유 표본이 27건뿐이므로 궤도·속도 파라미터와의 관계는 **일반화 불가**
- `days_since_start`가 along·across에서는 양의 상관, total에서는 음의 상관으로 나타남. 오차 성분 간 상쇄 가능성을 시사하나 미확인
