# eo/bluebon/downstream

**응용.** L1C 영상을 받아 대기·해양·화질 쪽으로 확장한 작업들.

## 하위

| 디렉터리 | 내용 |
|---|---|
| [`aod/`](aod/) | 에어로졸 광학두께(AOD) 산출·검증 — MODIS MCD19A2 대조. |
| [`dehazing/`](dehazing/) | 연무 제거 — 처리 파이프라인과 윈도우 GUI. |
| [`enhancement/`](enhancement/) | 화질 개선 실험 (모델 본체는 제3자라 미포함). |
| [`ocean-color/`](ocean-color/) | 해색 — 고유광학특성(IOP) 역산과 적조(HAB) 탐지. |
| [`super-resolution/`](super-resolution/) | 초해상화 추론 호출. |
