═══════════════════════════════════════════════════════════════
  FEE/CEM 자동화 — 두 가지 방식
═══════════════════════════════════════════════════════════════

작업 폴더 (둘 다 공통):
<WORK_ROOT>/prep/data/fee_cee_temp


┌─────────────────────────────────────────────────────────────┐
│ 방식 A.  압축파일 기반                                       │
│ → 로컬에 .tar.xz가 있을 때 사용                              │
└─────────────────────────────────────────────────────────────┘

  사용 시점:
    위성영상 압축파일을 직접 받았을 때

  순서:
    1. .tar.xz 파일을 <WORK_ROOT>/prep/data/ 에 둔다
       (파일명 규칙: YYYYMMDD_<지역>.tar.xz)
    2. 실행:

cd <WORK_ROOT>/prep/data/fee_cee_temp
rm -rf data/fee_cee_temp/downlink data/fee_cee_temp/result
rm -f data/fee_cee_temp/archive_capture_map.csv
./process-all.sh

  동작:
    압축 해제 → imaging-test 실행 → 결과 생성
    → 같은 이름의 Drive 폴더에 telemetry/, result.txt 업로드
    → 시트 AD열에 입력 (날짜 + 지역명으로 매칭)

  옵션:
    SKIP_DRIVE_UPLOAD=1 ./process-all.sh    # Drive 업로드 빼기
    SKIP_SHEET_UPDATE=1 ./process-all.sh    # 시트 입력 빼기


┌─────────────────────────────────────────────────────────────┐
│ 방식 B.  시트 기반 (Drive에서 직접)                          │
│ → Drive에 raw/만 올라와 있을 때 사용                         │
└─────────────────────────────────────────────────────────────┘

  사용 시점:
    Drive에 폴더(raw/ 포함)는 있지만 시트 AD열이 비어있을 때

  순서:
    1. 실행:
./process-from-drive.sh

  동작:
    시트 AD 빈 행 찾기 → E열 시각으로 Drive 폴더 매칭
    → (시차 20초 이내만) → raw 다운로드 → imaging-test 실행
    → telemetry/, result.txt 를 Drive에 업로드
    → 시트 AD열에 FEE/CEM 입력

  옵션:
    --dry-run                  # 매칭만 확인, 다운/입력 안 함
    --date 2026-05-11          # 특정 날짜만
    --limit 5                  # 처음 N개만
    654 685                    # 특정 시트 행번호만
    (조합 가능)

  예시:
    ./process-from-drive.sh --dry-run                # 전체 미리보기
    ./process-from-drive.sh --date 2026-05-11        # 한 날짜만
    ./process-from-drive.sh --date 2026-05-11 --dry-run
    ./process-from-drive.sh                          # 전부 실제 실행


═══════════════════════════════════════════════════════════════
  어느 걸 써야 하나?
═══════════════════════════════════════════════════════════════

  새 영상 .tar.xz 받았다  →  방식 A (process-all.sh)
  Drive에 raw만 올려놨다  →  방식 B (process-from-drive.sh)
  시트에 비어있는 행 채우고싶다  →  방식 B (process-from-drive.sh)


═══════════════════════════════════════════════════════════════
  공통 안전장치
═══════════════════════════════════════════════════════════════

  · 시트 AD에 이미 값 있으면 덮어쓰지 않음
  · Drive에 같은 이름 파일 있으면 재업로드 안 함
  · 시차 20초 초과 시 매칭 안 함 (방식 B)
  · 폴더에 .tlm.tpx 파일 없으면 그 행은 스킵 (방식 B)


═══════════════════════════════════════════════════════════════
  문제 발생 시
═══════════════════════════════════════════════════════════════

  "Nothing to update" / "no row matched"
    → 매칭 조건이 맞는 행/폴더가 없음. dry-run으로 확인

  "no folder on <date>"
    → Drive에 그 날짜 폴더가 없거나, 시차가 20초 초과

  "403 PermissionError"
    → 시트에 <SERVICE_ACCOUNT_EMAIL> 편집자 공유 확인
