# steps — 단계 0~4 와 좌표 정합

단계는 순서가 있고, 앞이 실패하면 뒤는 건너뛰되 **그 사실을 결과에 적음**.

## 본 단계

| 파일 | 단계 | 입력 | 출력 |
|---|---|---|---|
| `s0_locate.py` | 0 주소 해석 | 지번 주소 | 좌표, 필지 폴리곤·PNU, 건축물대장 표제부, 사용할 영상 |
| `s1_building.py` | 1 건물 (모델) | 정사영상, 필지 | 지붕 폴리곤 → 정합 → 지번 귀속. **나머지 셋이 전부 이 위에 섬** |
| `s2_yard.py` | 2 야적물 (A4·A5) | 필지 − 건물 영역 | 적재 구역. 건물을 어두운 베일로 덮어 톱날 지붕을 적재물로 오독하지 않게 함 |
| `s3_separation.py` | 3 이격거리 (A1) | 건물 폴리곤 | 둘레 도달거리 안의 상대까지 최단거리. 규칙은 `rules.py`(`SEP_REACH_M` 11.3 m) |
| `s4_ledger.py` | 4 대장 대조 (A3) | 건물 면적, 대장 건축면적 | 증축 판정. **건축면적 하나만 비교함** — 연면적은 층수가 곱해져 비교 대상이 아님 |

## 좌표 정합 보정

탐지 폴리곤을 실좌표·필지에 맞추는 보정임. **옮기는 대상은 영상이고 지도 기하는 그대로 둠.**

| 파일 | 역할 | 입력 | 출력 |
|---|---|---|---|
| `parcel_fit.py` | 정사영상 지오레퍼런스 편이 **측정**. 연속지적도 필지와 GIS footprint 가 같은 방향으로 함께 어긋나는 것을 근거로 삼음 | 필지·footprint·영상 | 편이 벡터 |
| `georef.py` | 측정한 편이로 **영상을 보정** | 영상, 편이 | 보정된 지오레퍼런스 |
| `parcel_bias.py` | 연속지적도 **레이어 고유 편이** 보정 — 영상을 고쳐도 대구에서는 필지가 맞지 않아 따로 둠 | 필지 레이어 | 보정된 필지 |
| `align.py` | 정합 2차 — 모델 폴리곤으로 보정 결과를 확인하고 마무리 | 모델 폴리곤 | 확정된 정합 |
| `gt_parallax.py` | 이식해 온 GT 의 **지붕 시차 잔차**를 해당 지번에서 재서 그만큼 GT 를 옮김 | 1차 영상 GT, 2차 영상 | 시차 보정된 GT |

## 실행

> 새 영상·새 자료가 들어왔을 때 이 모듈만으로 결과까지 가는 순서임.
> 아래 인자와 상수는 코드에서 그대로 뽑은 것임.

### 환경

```bash
conda activate pyps      # geopandas · rasterio
```

- 환경 정의: [`environment/`](../../../../../environment/)
