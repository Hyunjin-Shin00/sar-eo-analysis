# report — 값 하나를 종이 한 부로

`result.json` 과 그림을 받아 물건별 보고서를 HTML·PDF 로 냄. 둘은 같은 판짜기를 씀.

| 파일 | 역할 | 입력 | 출력 |
|---|---|---|---|
| `single.py` | 단일시점 보고서 6면 | `result.json`, `0~3_*.png` | `보고서.html` · `.pdf` |
| `compare.py` | 두 촬영일 **비교분석** 보고서 4면. `single` 의 함수를 그대로 씀 | 두 시점 결과 | `위성_비교분석_<주소>.html` · `.pdf` |
| `pdf_refit.py` | 손으로 만든 보고서 PDF 의 **판짜기는 그대로 두고 값·그림만** 산출물로 교체 | 원본 PDF, 결과 | 값이 맞춰진 PDF |
| `refit.py` | `pdf_refit` 의 부품 — **무엇을 적을지**를 값에서 뽑음. 물건 이름은 여기 없음 | `result.json` | 치환할 문자열 묶음 |

## 브랜딩

- 원본 보고서 머리글은 고객사 로고(워드마크 PNG)와 사명을 넣게 돼 있었음
- 공개본에서는 로고 자산 `assets/brand/*.png` 를 **포함하지 않음**
- 코드의 로고 파일명은 중립 자리표시자 `client_logo.png` 로, 코드·주석의 고객사명은 "고객사" 로 치환함
- 로고 파일이 없으면 코드가 **머리글을 비워 그림**(빈 brand div) — 정상 동작은 유지됨
