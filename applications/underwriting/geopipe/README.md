# geopipe — 미포함 (접근 불가)

대장·지적·멸실 수집 플랫폼 `geopipe` 는 이 번들에 담지 못했음.

- 소스는 동료 홈 디렉터리(`/home/<동료>/<client>/geopipe`)에만 있고, 이 작업 계정의 권한으로는 읽을 수 없음.
- 전체 파일시스템 검색 결과 다른 위치에 읽을 수 있는 사본 없음.
- 동료 계정 자격증명으로 로그인해 꺼내오지 않음(공개 번들에 타인 계정 접속으로 얻은 코드를 담지 않는다는 원칙).

가져오려면 소유자가 직접 추출해 `code/geopipe/` 에 넣고, 같은 규칙(자격증명 제거·경로 일반화)을 적용해야 함. 참고로 과거 실사 기록상 `geopipe` 는 `.env` 에 키 4개를 두고, 철거멸실대장·층별개요 API 로 `buildings.gpkg`(report-gen 의 입력 GIS)를 생성하는 수집기임.
